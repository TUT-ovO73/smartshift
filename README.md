# 智排班 SmartShift

面向高校学生组织 / 社团值班 / 实验室值守场景的智能排班系统。基于**可解释的加权评分模型**自动生成排班草案，管理员确认后一键发布，配合签到与积分信用体系形成完整管理闭环。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 · Element Plus · Pinia · Vue Router · Axios · Vite |
| 后端 | Node.js 24 · Express 4（ES Modules） |
| 数据库 | SQLite（Node 内置 `node:sqlite`，零原生编译依赖） |
| 认证 | JWT（HS256）· bcryptjs 密码哈希 |

## 核心功能

- **智能排班**：班次优先级排序 → 5 条硬约束过滤（时段可用 / 班次不重叠 / 间隔≥8h / 日≤8h / 周≤40h）→ 6 因子加权评分 → 贪心匹配
- **可解释性**：每次分配附带评分明细（reason），前端可视化展示"为什么安排 TA"
- **草案 / 发布分离**：生成结果先以草案呈现并提示冲突，管理员确认后才事务批量落库
- **签到闭环**：成员按钮签到 → 管理员确认 → 积分与信用分自动结算
- **积分信用体系**：按时完成 +10 / 特殊班 +5 / 替班 +8 / 缺席扣信用分
